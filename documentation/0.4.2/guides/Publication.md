## Download and verify

The release supplies `riskium-v0.3.5-source.tar.gz`, `source-manifest.json`, `artifact-versions.json`, `freeze-receipt.json`, `release-notes.md` and `SHA256SUMS.txt`. Check the five payload checksums before extracting the source. The source manifest identifies every archived file. [Reproduction instructions](Reproduce.md) separate the release checks from a new execution.

The freeze receipt records the phase before publication and therefore retains `publication_executed: false`. Actual publication and independent public downloads have a [separate completion record](https://github.com/ArazSaieArasi3/riskium/issues/59). The [live Latest link](https://github.com/ArazSaieArasi3/riskium/releases/latest) is convenient; use the exact release when citing results.
