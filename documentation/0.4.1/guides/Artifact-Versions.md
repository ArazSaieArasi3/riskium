# Versions and artifact roles

Riskium versions several artifacts separately. Source release **v0.3.5** packages the research and engineering files; it does not mean that the ontology or paper has that version.

| Artifact | Version | Role |
| --- | --- | --- |
| Published source distribution | **v0.3.5** | 29 selected components and six independently verified assets |
| Native conceptual model / exchange / bounded OWL | **0.3.1** | Unchanged semantic source and its bounded representations |
| Ontology requirements (ORSD) | **0.4.3** | Original definitions, priorities and acceptance populations |
| Original relational requirements (DRSD) | **0.1.0** | Original database requirements; later profiles add explicit supplements |
| Public SQL profiles | **0.1.0–0.7.0** | Additive database profiles, through migration 8 |
| Current consistency | **0.3.0** | 450 accounting routes and 39 declared current claim routes |
| Released documentation baseline | **0.4.0** | The explanatory sources included in the immutable v0.3.5 package |
| Maintained documentation | **0.4.1** | Published-status correction, clearer reading paths and editorial maintenance |
| Approved manuscript | **7.0.8** | Checked Word/PDF baseline; later SQL executions are not silently added to its claims |

## Current views and frozen history

Wiki and `/current/` are maintained reading surfaces. They point to exact semantic/evidence sources and the published release. For scholarly reproduction, use an immutable source tag or commit rather than assuming the current page will always retain the same wording.

The [version index](https://arazsaiearasi3.github.io/riskium/versions/index.html) exposes four frozen documentation snapshots. They preserve their original content and version labels. Earlier 0.3.0 and 0.4.0 documentation source namespaces also remain intact. A historical statement that work was pending describes its own checkpoint.

There are twelve published source releases: seven development prereleases and five stable distributions. The latest is [v0.3.5](https://github.com/ArazSaieArasi3/riskium/releases/tag/v0.3.5); its [publication record](https://github.com/ArazSaieArasi3/riskium/issues/59) verifies preservation of all eleven earlier releases. [Publication](Publication.md) explains downloads and citation. The next source-distribution version and scope have not yet been selected.
