# Competency questions and source populations

## Derived nature-task questions

Two supplementary questions ask what an exact issued nature version recorded and which versions belong to an explicitly declared correction family. The [NRA contract](https://github.com/ArazSaieArasi3/riskium/blob/674886381b5520e0771b3a958919e735327572c2/implementation/relational/0.9.0/contract.json) links them to original CQ06 provenance, CQ07 declared lineage and CQ08's no-invented-case principle. It does not reclassify or pass the original scenario populations, establish truth or independent corroboration. Follow [the domain example](Using-the-Model.md#risk-nature-history), [exact expected answers](Reproduce.md#risk-nature-example) and [source/result trace](Traceability.md).

Eight original CQ contracts connect uses to expected answers. Five selected synthetic tasks concern shared case identity, scenarios, assessment comparability, assignments without asserted mandates and closure without cessation. Across all eight contracts, the baseline asserted-graph SPARQL suite has **32 fixed-answer cases and eight query mutants**, including missing/conflicting-data controls.

[Original CQ contracts](https://github.com/ArazSaieArasi3/riskium/blob/58ff468ec4e8f3500ace6869601a25ea263c3d9f/requirements/cq/README.md) and [definitions](https://github.com/ArazSaieArasi3/riskium/blob/58ff468ec4e8f3500ace6869601a25ea263c3d9f/requirements/competency-questions.json) retain their source populations and original acceptance criteria. Synthetic tests are not independently prepared stakeholder/source populations; trace accounting does not complete those criteria.
