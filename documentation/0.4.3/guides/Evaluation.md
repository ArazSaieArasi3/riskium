# Evaluation: results and their limits

Riskium separates formal consequences, data validation, software behavior and independent judgment. Each result applies to its declared inputs and task. A requirement, expected answer, actual execution and expert assessment are different kinds of evidence.

## Formal and data checks

| Evidence | Recorded result | Interpretation boundary |
| --- | --- | --- |
| HermiT baseline | 281 PASS / 14 NOT_RUN of 295 obligations; 693 matching executed cases | Bounded OWL consequences, not a whole-model correctness percentage |
| SHACL historical baseline | 341 scoped PASS / one PARTIAL / 17 NOT_RUN of 359 | Explicit-data modules, not complete risk-record admission |
| Original synthetic competency questions | 32 fixed answers and eight detected query mutants | Separate from independently prepared source populations |

The [formal-method guide](Formalization.md) connects all 25 interpretation clauses to their original statements, assumptions and outcomes. Those historical engine populations are unchanged by later database or documentation work.

## Source, software and trace evidence

| Evidence | Recorded result | Interpretation boundary |
| --- | --- | --- |
| Source-backed supplements | 13 CQ06 statements; five original/reissued CQ07–08 pairs and eleven withheld candidates | Finite inspected cohorts remain separate from synthetic controls |
| Source/scenario, lineage, qualified evidence and lifecycle SQL | 54 / 54 / 62 / 43 fixed controls | Four engineering populations; no pooled accuracy claim |
| Historical v0.3.5 publication checkpoint | 495 software tests, 28 core checks and 13 release checks | Exact-source engineering results, not independent semantic ratings |
| Current consistency | 450 accounting routes, 39 declared current claim routes | Accounting coverage, not complete native mapping or scientific success |
| Approved paper | Actual 7.0.8 Word/PDF and claim locations checked | Later engineering is not silently added to the paper |
| Independent semantic review | Zero actual ratings | No independent acceptance is inferred |

All eleven organizational case admissions remain withheld. Source-faithful extraction, arithmetic or publication does not establish true incidents, calibrated prediction, organizational benefit or semantic adequacy.

## Follow a result to its evidence

Read [quality and limitations](Quality.md) before drawing a broader conclusion.
