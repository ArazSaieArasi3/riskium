# Documentation comparison and history

The [dated OntoSPK comparison](https://github.com/ArazSaieArasi3/riskium/blob/58ff468ec4e8f3500ace6869601a25ea263c3d9f/docs/publication-comparison.md) records inspected public interfaces and documentation needs at its own source/date. Earlier statements about missing routes or pending publication are historical observations, not the current release state.

## Current reading surfaces

The current explanation is shared between native Wiki and Pages. Pages also exposes the conceptual reference, bounded OWL/WIDOCO reference, graph tools, downloads and four frozen documentation snapshots. Source **v0.3.6** is published; documentation **0.4.3** maintains its reader-facing explanation.

The Wiki provides curated explanations and reader navigation. Pages adds generated references and interactive exploration. Both point to the same governed sources rather than defining separate models. [Visualization](Visualization.md) explains the roles of each reference tool.

## What the comparison does not establish

Available reading routes support inspection and reproduction. They do not establish broader ontology coverage, semantic equivalence, usability superiority or better organizational decisions. Such claims would require a study with declared users, tasks and actual outcomes. The current editorial/rendered review is an agent inspection, not a controlled user study or independent expert validation.

[Publication](Publication.md) identifies exact versions; [limitations](Limitations.md) separates documentation quality from scientific acceptance.
