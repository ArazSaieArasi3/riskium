# Competency questions and source populations

Eight original CQ contracts connect uses to expected answers. Five selected synthetic tasks concern shared case identity, scenarios, assessment comparability, assignments without asserted mandates and closure without cessation. Across all eight contracts, the baseline asserted-graph SPARQL suite has **32 fixed-answer cases and eight query mutants**, including missing/conflicting-data controls.

[Original CQ contracts](https://github.com/ArazSaieArasi3/riskium/blob/ccc89a184a618ccc2c107ccbf27a15232060557e/requirements/cq/README.md) and [definitions](https://github.com/ArazSaieArasi3/riskium/blob/ccc89a184a618ccc2c107ccbf27a15232060557e/requirements/competency-questions.json) retain their source populations and original acceptance criteria. Synthetic tests are not independently prepared stakeholder/source populations; trace accounting does not complete those criteria.

## Later source-backed evidence

CQ06 separately inspects 13 source statements. CQ07/CQ08 separately inspect five original/reissued assertion pairs and eleven documentary identity candidates already marked WITHHELD. Source locators, interpretation origins, raw candidates and correction metadata are supplementary application fields, not new native OWL properties. The finite supplements retain separate source queries, synthetic controls and scope.
