# Quality claims and limits

The current evidence supports catalog integrity, selected bounded formal consequences, source-preserving retrieval and finite engineering contracts. It does not establish whole-ontology semantic correctness, universal standards compliance, full native mapping or organizational benefit.

## Assess the right population

Historical HermiT remains **281 PASS and 14 NOT_RUN of 295**. Historical SHACL remains **341 scoped PASS, one PARTIAL and 17 NOT_RUN of 359**. Later source-backed, SQL and software tests retain their own input hashes and execution populations. Documentation and successful downloads add publication evidence, not new independent semantic judgments.

The original synthetic CQ suite has 32 answer cases and eight query mutants; original independent population acceptance remains distinct from later finite CQ06–CQ08 source supplements. All 306 native IDs are accounted for, including 236 deferred mappings. Eleven source-local organizational admissions remain WITHHELD and independent ratings remain zero.
