# Evaluation and evidence populations

Riskium's evidence is organized by the claim and population evaluated. A requirement, expected oracle, actual execution, owner scope decision and independent judgment remain different records. Model 0.3.1 is unchanged; published source is v0.3.4 and the target is v0.3.5.

| Evidence population | Retained outcome | Boundary |
| --- | --- | --- |
| HermiT baseline | 281 PASS / 14 NOT_RUN of 295 obligations; 693 matching executed cases | Bounded OWL consequences, no whole-model correctness percentage |
| SHACL historical baseline | 341 scoped PASS / one PARTIAL / 17 NOT_RUN of 359 | Explicit-data modules, not complete risk-record admission |
| Original CQ synthetic suite | 32 fixed answers and eight detected query mutants | Not eight accepted independent source populations |
| Source-backed supplements | 13 CQ06 statements; five original/reissued CQ07–08 pairs and eleven WITHHELD candidates | Finite source cohorts remain separate from synthetic controls |
| SSC/SCL/EQR/ELC SQL | 54 / 54 / 62 / 43 fixed controls | Four separate engineering populations; no accuracy pooling |
| Current consistency | 450 accounting routes, 39 declared current claim routes | Accounting, not scientific success or complete mapping |
| Approved paper | Actual 7.0.8 Word/PDF and claim locations checked | Later engineering is not silently added to the paper |
| Independent semantic review | Zero actual ratings | No invented respondents or adjudication |

[Detailed formal-method guide](Formalization) retains all 25 original clauses and engine outcomes. [Quality and limits](Quality), [traceability](Traceability) and [database assurance](Database-Assurance) connect the actual evidence to its permitted claims. All eleven organizational case admissions remain WITHHELD. Source-faithful arithmetic, extraction or publication does not establish true incidents, calibrated prediction, benefits or semantic adequacy.
