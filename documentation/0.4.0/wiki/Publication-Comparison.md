# Documentation comparison and historical evidence

The [dated OntoSPK comparison](https://github.com/ArazSaieArasi3/riskium/blob/ccc89a184a618ccc2c107ccbf27a15232060557e/docs/publication-comparison.md) records the inspected public interfaces and documentation needs at its own source/date. Its earlier statements about missing current routes or pending first publication are historical observations. They are not the current Riskium release status.

## Current Riskium routes

Documentation 0.4.0 provides shared explanatory guides on native Wiki and Pages, a conceptual reference, bounded OWL/WIDOCO views, graph tools, downloads, traceability, a work plan and immutable documentation snapshots. Published stable source is v0.3.4; target v0.3.5 remains under #51. #55 records the actual current-channel publication and independent byte readback.

These routes support inspection and reproduction. They do not establish broader ontology coverage, semantic equivalence, usability superiority or better organizational decisions. A matched study with declared users/tasks and actual outcomes would be needed for such claims. [Visualization](Visualization), [publication](Publication) and [limitations](Limitations) explain the supported roles.
