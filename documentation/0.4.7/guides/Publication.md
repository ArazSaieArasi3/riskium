# Publication and verification

The v0.3.8 package makes the model, current concept dictionary and manuscript-review evidence accessible in one source distribution. The verified publication banner and source record identify whether the package is prepared or actually published. A frozen receipt retains its prepublication phase after the later publication occurs.

## Download and reproduce

Obtain all six assets from the [exact release](https://github.com/ArazSaieArasi3/riskium/releases/tag/v0.3.8): `riskium-v0.3.8-source.tar.gz`, `source-manifest.json`, `artifact-versions.json`, `freeze-receipt.json`, `release-notes.md` and `SHA256SUMS.txt`. Verify all five payload checksums, extract the archive, then run its standard-library verifier with the exact source from the trusted publication. [Reproduction](Reproduce.md) provides commands.

The six uploaded assets are distinct from GitHub's automatically generated source ZIP/tar files. Internal checksum agreement is not authenticity; compare the archive digest and source with a trusted publication. The public publication record follows qualification, draft verification and independent public downloads.
