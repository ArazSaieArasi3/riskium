# Relational companion: current boundary

Riskium includes a relational companion and bounded synthetic SQL/RDF experiments. The historically published [SQLite implementation 0.9.0](https://github.com/ArazSaieArasi3/riskium/tree/ce0baefa3495d1bc3b42f56ad578154d5bc4f178/implementation/relational/0.9.0) retains its original schema/model role. It has not been silently requalified as a complete implementation of scientific model 0.3.2.

The successor's identity/history slice actually supports an analytical case without register entries, multiple entries for one case, distinct cases with equal labels and rejection of cross-family revisions. The evidence-use sidecar exercises explicit use, reference participation, grounding, context and purpose. Selected SQL/SPARQL answers were checked under these bounded fixtures.

These results establish useful implementation examples for the tested slices. Full context/approval persistence, a complete ontology-to-relational migration, production workloads and PostgreSQL implementation remain open. Historical pharmaceutical withheld-admission judgments retain their original profile and are not automatically converted into operationally admitted cases.
