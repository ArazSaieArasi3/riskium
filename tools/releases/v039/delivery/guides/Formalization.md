# Formalization and implementation

The authoritative 0.3.2 catalog declares concepts, stereotypes, associations, multiplicities, inheritance, constraints and explicit generalization sets. The generated native OntoUML exchange preserves the selected structural inventory. Its typed OWL/Turtle projection implements the declared bounded logical mapping; prose constraints and application tasks retain their stated roles.
