# Traceability and source roles

The public package binds scientific source 0.3.2, native/OWL projections, explicit-data profiles, the complete 0.4.9 dictionary and packaging tools to an exact source selection. The maintained reader is a later publication adapter: it updates publication labels and routes while retaining the selected authored definitions and structural bindings.

Each current concept page links its exact qualified source dossier and equivalent Wiki/Pages body. The current publication manifest inventories delivered file hashes; the release's source manifest inventories the frozen distribution. Neither substitutes for the other.

Original model 0.3.1, historical SQL/corpus fixtures and manuscript evidence retain their own source versions. New results do not overwrite earlier receipts, convert hypothetical statements into occurrences or treat withheld source-derived candidates as independently admitted operational risks.
