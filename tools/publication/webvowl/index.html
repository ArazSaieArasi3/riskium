Source, interpretation and reuse

The fixed projection is generated from the exact released Turtle at semantic source 8afe169968b5. It depicts 78 named classes, 127 object properties and 66 named subclass links. Three optional conceptual boundaries are outside this OWL core. Restrictions, disjointness, annotations and other omitted statements remain in the OWL and conceptual references.

All runtime files and data are local to this site. This shell has no ontology upload, editor, remote-ontology input, conversion service, analytics or persistent browser storage. Search, selection, pan and zoom affect only the view; the downloaded JSON is the fixed projection, not a newly edited ontology.
