# Source-qualified concept definitions

The authoritative [review registry](review.json) records a documentary decision for all 80 Riskium concepts. [The generated review report](../../../documentation/0.4.8/concepts/External-Definitions.md) provides the source register and concept-by-concept table; [each dossier](../../../documentation/0.4.8/concepts/README.md) includes the relevant external paraphrase and exact locator.

This is a bounded assistant-supported source comparison. It is not a claim of exhaustive literature coverage, independent expert validation, or formal standards compatibility. Each comparison preserves the ontology's authored definition. No external definition is forced onto an application-specific concept.

The nine sources include fixed-date W3C Recommendations, a clearly labeled DQV Working Group Note, selected NIST security guidance, two unversioned OntoUML construct pages and an ISO edition catalogue. Eight directly retrieved response bodies have SHA-256 identities; the Mode entry was inspected through indexed primary-source text after direct HTTP 403 and deliberately has no response hash. Source bodies and restricted standard text are not redistributed. All paraphrases are short and labeled; no quotation is implied.

Formal equivalence, subsumption and independent ratings remain unassessed. The six scoped no-direct-equivalent decisions refer only to the inspected entries, without asserting that no relevant external ontology exists. Three normative terms remain deferred to [#78](https://github.com/ArazSaieArasi3/riskium/issues/78). [#23](https://github.com/ArazSaieArasi3/riskium/issues/23) owns independent semantic interpretation.
