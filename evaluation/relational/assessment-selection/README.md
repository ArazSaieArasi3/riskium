# Assessment selection execution

The bounded SQL 0.8.0 component implements explicit selection, withdrawal, clear and historical retrieval of complete issued assessment bundles. Its original declaration and literal expected answers remain immutable. [Actual control results](report.json), [legacy regression results](legacy-regressions.json) and [trace routes](traceability.json) describe the executed scope under [#61](https://github.com/ArazSaieArasi3/riskium/issues/61).

The 44 prospective controls execute populated migration, context/as-of queries, source and native graph preservation, invalid direct SQL/API writes, nested rollback, real backup/reopen, digest-checked restore and actual wrong-query/weakened-guard experiments. Twelve further regression tests check caller source/timestamp handling and additional transaction, sequence and restoration boundaries. Original relational/evidence suites are replayed separately.

The report retains expected and observed values, actual diagnostics and mutation outputs. These are synthetic engineering checks. Counts do not measure ontology correctness, independent semantic judgment or real organizational case acceptance. Original source populations and the 687 selected v0.3.5 file bindings remain preserved.

The component guide explains a concrete two-context example, all API inputs, state meanings and source boundaries. Six future reader criteria remain attached to #61/R4; the new feature has not yet been published through the current Wiki/Pages. Exact source, hosted execution and artifact readback are recorded in #61 after they occur.

Full repository integration, current trace/manuscript overlay, reader-channel review and v0.3.6 freeze/publication remain #61/R3–R5. The published source remains v0.3.5 and the approved manuscript remains 7.0.8.
