## Exact task and focus

The caller supplies five named identities outside the raw graph: request, left assessment, left dimension result, right assessment, right dimension result. The runner adds only four private selector links to the effective graph; raw input containing these selectors is rejected. The request is an application envelope, not a new native domain class. Dropping an assessment/result type cannot make the requested focus disappear. Raw mode preserves supplied assertions and supplies no managed comparability verdict.

C-13 checks each selected DimensionAssessmentResult's explicit usesScale, selectsLevel, dimension and usesScaleVersion. The selected level must have levelOf for that scale, and the scale's scaleForDimension must agree with the selected dimension. The native model has no level-to-scale-version relation, so versioned application metadata `levelScaleVersion` supplies that declaration. Both selected and level-declared versions require the proper explicit versionOf scale target. Unknown mappings are not silently resolved. These are specification/record joins; presence of a declaration does not prove its external meaning.

C-18 checks that each selected result is explicitly a hasDimensionResult member of its selected assessment; method permitsScale and specifiesDimension must explicitly support it. The assessment requires singleton method/method version, basis/basis version, context/context version, temporal context and source. Native R-46/RX-015, R-12 and R-45/RX-014 are used where they exist. `basisVersion`, `temporalContext` and `source` are supplementary application fields. Each versionOf target must agree with the actual selected artifact. The two sides must match method/version, scale/version, dimension, basis/version, context/version and temporal-context identity for direct comparison under this strict policy.

Temporal context is an opaque declared interpretation identity, not an interval/timestamp validator. Basis-version equality is a supplementary snapshot declaration, not evidence that the basis was immutable in storage. Method permissions are checked on the declared artifact links; their exact version-specific issued payload and historical dependency preservation require separate #12 evidence. Different selected levels may be eligible for comparison on the same pinned scale; the module does not order them or calculate a risk score. A transformation hint in input does not implement a governed transformation. Unrelated reported numeric codes are preserved without affecting eligibility, and no missing field is replaced with zero.

## Identity, decisions and integration

Asserted named instance sameAs normalizes before counting/comparison. Explicit differentFrom supplies known distinction; different names, equal labels and equal numeric codes cannot establish equality or incompatibility. Schema/import injection, reserved-vocabulary aliases, caller-focus injection and conflicting identity assertions reject before engine execution. Only pinned source subclass triples are appended; inference is none, imports disabled, no native domain/range or anonymous-filler repairs.
