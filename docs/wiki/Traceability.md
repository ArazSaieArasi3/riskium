Use `--write` only after reviewing an intentional input/oracle change. The query receipt records execution time, Python/RDFLib versions, per-case expected/observed rows, graph snapshots, query hashes and the declared inference policy. A query error never counts as a detected mutant. Negative and conflicting fixtures are retrieval tests, not claims that those graphs satisfy managed admission. Missing asserted values are not logical negation.
