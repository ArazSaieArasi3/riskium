# Visualizing Riskium

The selected conceptual diagram places the main risk-knowledge distinctions in a readable subset. The complete conceptual diagram includes the full catalog and its boundary notions. Both diagrams are derived inspection aids; they do not replace source definitions or establish semantic acceptance.

The current [OWL explorer](https://arazsaiearasi3.github.io/riskium/current/explore/index.html) follows asserted named parents/children and property domains/ranges. It contains 78 named classes and 127 object properties from the declared OWL graph, works as hypertext without JavaScript, and filters text locally. It does not infer facts or upload an ontology.

The [WIDOCO reference](https://arazsaiearasi3.github.io/riskium/current/widoco/index-en.html) describes the actual bounded OWL export and its source/tool identity. Four RDF download serializations are checked for graph isomorphism; the original Turtle remains byte-preserved.

Graphical **WebVOWL is not yet implemented in Riskium**; [issue #32](https://github.com/ArazSaieArasi3/riskium/issues/32) specifies it as an additional source-bound view. A future viewer must declare omitted anonymous/unsupported expressions, retain local assets/notices, preserve the accessible fallback, and pass actual deployed loading/search/navigation checks. OntoSPK's viewer data and browser results do not count as Riskium evidence.
