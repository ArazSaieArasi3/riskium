# Requirements and competency questions

The ontology requirements describe the information Riskium must distinguish and preserve. Competency questions specify tasks that can expose missing distinctions or unjustified inferences. Acceptance and rejection cases are recorded separately.

The current public specification contains twelve requirement families, eight scope obligations and eight selected competency-question contracts. These populations are not interchangeable and are not an overall completion percentage.

Read the [requirements specification](https://github.com/ArazSaieArasi3/riskium/blob/main/requirements/ontology-requirements.md) and [engineering policy](https://github.com/ArazSaieArasi3/riskium/blob/main/requirements/engineering-policy.md).
