# Inspect and use the model

Use the complete model for the catalog, definitions, relations and constraints. The typed projection excludes the optional phenomenon boundaries. It is a derived view, not a separate semantic authority.

Conceptual diagrams aid inspection. They do not replace the model or certify native editor conformance. A selected view is a subset; the complete view requires zoom for individual labels.

Follow the [reproduction instructions](https://github.com/ArazSaieArasi3/riskium/blob/main/docs/reproducibility.md) to validate the source and build the local reference. The [bounded OWL export](https://github.com/ArazSaieArasi3/riskium/blob/main/ontology/derived/riskium.owl.ttl), [HermiT report](https://github.com/ArazSaieArasi3/riskium/blob/main/evaluation/hermit/report.md) and [SHACL ledger](https://github.com/ArazSaieArasi3/riskium/blob/main/evaluation/shacl/coverage-status.md) describe distinct, limited formal checks. The [release-claim inventory](https://github.com/ArazSaieArasi3/riskium/blob/main/evaluation/release-claims.md) names the open routes.
