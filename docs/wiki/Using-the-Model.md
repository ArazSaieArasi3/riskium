# Inspect and use the model

Use the complete model for the catalog, definitions, relations and constraints. The typed projection excludes the optional phenomenon boundaries. It is a derived view, not a separate semantic authority.

Conceptual diagrams aid inspection. They do not replace the model or certify native editor conformance. A selected view is a subset; the complete view requires zoom for individual labels.

Follow the [reproduction instructions](https://github.com/ArazSaieArasi3/riskium/blob/main/docs/reproducibility.md) to validate the source and build the local reference. Formal reasoning and explicit-data validation require the encodings and fixtures tracked in the roadmap.
