Frozen release evidence: HermiT: 693 executed cases PASS; 281/295 baseline obligations, 14 NOT_RUN. SHACL: 341 scoped PASS, 1 PARTIAL and 17 NOT_RUN of 359 obligations. Independent semantic acceptance remains open.

Evaluation status

This snapshot has migration-integrity, structural, coverage-design, native-exchange, bounded OWL-mapping, scoped HermiT and scoped SHACL checks. They verify the exported inventory, references, endpoint cardinality syntax and direction, inheritance structure, publication boundary, official exchange-schema conformance, SDK interoperability, OWL Turtle syntax and source mapping, and the executed reasoning/validation cases. They do not establish domain adequacy, complete OntoUML semantic conformance or full explicit-data conformance.

The post-prerelease requirement/CQ trace reconciles 28 public source obligations and links their current evidence and gaps. The query receipt records 40 actual synthetic SPARQL executions: 32 fixed answer cases and eight detected query mutants. Five original synthetic-task contracts have bounded execution; CQ06–CQ08 have synthetic controls only and still lack their declared independently prepared population. Supplementary scalar/provenance/lineage fields are explicitly separated from native OWL. This completes traceability, not full requirement or independent semantic acceptance.

The native model review records the source-preserving exchange representation, ten design dispositions, explicit generalization-set policy and legacy verifier limitations.

The OWL mapping review records the three pinned inputs, axiom choices, import and identity decisions, and disposition of all 25 interpretation constraints. The receipt records input and output digests and coverage counts. RDF parsing and regression checks are mapping checks, not logical reasoning.

The HermiT report records actual reasoning outcomes, the JSON receipt records every case, and the RDF/XML premise pins the exact input graph. The remaining-route review assigns the 14 unexecuted constraint rows and the explicit-data remainder of three bounded OWL passes. Its baseline fraction separates executed obligations from the constraints still lacking a sound HermiT oracle. Supplemental inference and mutation cases have their own denominator. This evidence does not substitute for SHACL, independent semantic review or empirical adequacy.

The first SHACL batch records explicit-data C-06/C-08/C-09/C-25 fixtures, profile decisions and exact JSON snapshots. The subsequent endpoint batch executes all 254 ordered ends of 127 typed relations. The current 359-row ledger now records 341 scoped PASS, one PARTIAL and 17 NOT_RUN (94.99% PASS coverage). The catalog admission batch adds 77 application metadata profiles and three boundary exclusions; it supports the limited CatalogInspection task. Both participants in all 127 relation pairs receive catalog admission or a separate imported-anchor type check alongside endpoint rules. The C-23/C-24 batch adds explicit context inclusion, matching revision/entry targets and cycle/same-entry checks. The C-11/C-12 batch checks application scheme keys and role-qualified evidence records; its policy keeps labels and source links from becoming identity or truth proofs. Selected cases combine endpoint and catalog rules. Full multi-relation/conditional integration, historical immutability and risk-assessment readiness remain separate. No HermiT outcome is changed into a SHACL pass.

The semantic assurance plan defines independent review, real-case and CQ evidence and the limits of numerical correctness claims. The semantic review register is an unadjudicated inventory; overall semantic correctness is unestimated, not 0% or an inherited test percentage.

The migration receipt states what was preserved and edited. The earlier coverage plan and test obligations identify planned formal work; their planning statuses predate the HermiT execution. Use the HermiT report for current reasoner outcomes.

The coverage contract records expected behavior, engine limits and planned routes for all 25 constraints. Its row review accounts for all 674 baseline obligations against exact source elements. Ten supplementary families retain imports, optional boundaries, scope requirements and integration work outside that baseline. The HermiT report records the subsequent scoped execution; the other formal and review routes remain distinct.

HermiT tests OWL consistency, class satisfiability and supported entailment/non-entailment on the reviewed mapping. SHACL is intended for declared explicit-data profiles. Constraints outside either formalism need an explicit policy, application check or review disposition; they must not disappear from the denominator.

Independent semantic review, case-based adequacy, standards interpretation, query answerability and reproducibility are separate evidence categories. A single aggregate pass percentage cannot replace these judgments.

Read the formal-validation plan and roadmap for remaining work.

Source and standards review

The post-prerelease source register records 11 selected sources, their exact editions/versions, dated primary locators, inspected portions and actual uses. Its 13 interpretation rows distinguish method use, vocabulary correspondence, semantic divergence, scope boundaries and one explicitly unassessed detailed vocabulary comparison. The integrity receipt checks identifiers, frozen model bytes and explicit claim/access limits; its PASS is an editorial integrity result, not semantic or normative acceptance. Full standards clauses, independent adjudication and exhaustive prior-art/novelty claims remain outside this completed #8 corpus milestone. The original engine and query counts are unchanged.
