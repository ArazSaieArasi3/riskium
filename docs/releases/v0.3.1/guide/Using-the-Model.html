Inspect and use the model

Start with the overview and scope, then inspect the complete conceptual source or selected diagram. The conceptual catalog has 80 concepts, 134 associations/bridges, 66 generalizations and 25 interpretation constraints; the imported anchor is listed separately. The bounded OWL export contains 77 local named classes, one anchor proxy and 127 object properties. Optional boundaries and seven bridges are excluded from that typed view.

Use the conceptual reference for full definitions, WIDOCO for asserted OWL commitments, and the hypertext explorer for named class/property neighborhoods. The visualization guide explains the distinction and the pending graphical WebVOWL enhancement. None of these views is an independent ontology authority.

For relational use, begin with the database assurance guide, derived DRSD and exact mapping/schema/query trace. SQLite assessment 0.2.0 is a selected, version-owned profile with unknown/zero and historical preservation rules. It is not a complete automatic translation of OWL into relational constraints, a migrated private database, a PostgreSQL implementation or a production-accepted application.

Follow reproduction before changing model, profile, schema, query or fixture. Each changed assumption invalidates its affected evidence. Record a concrete task and expected counterexamples first, preserve provenance and unresolved identity, and update the compatibility/trace records before a new release.
