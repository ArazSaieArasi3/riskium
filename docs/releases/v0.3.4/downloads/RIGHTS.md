# Rights, licensing and citation

On 22 October 2026 the project owner approved CC BY 4.0 for Riskium's original scientific content and MIT for its original software, with the three manuscript authors and their affiliations retained. See [LICENSE](LICENSE), the complete [CC BY 4.0](LICENSES/CC-BY-4.0.txt) and [MIT](LICENSES/MIT.txt) texts, and [AUTHORS.md](AUTHORS.md).

## Artifact scopes

| Scope | License |
| --- | --- |
| `ontology/`, including structured/native models, OWL exports and SHACL profiles | CC-BY-4.0 |
| `requirements/`, `diagrams/`, `docs/`, including Wiki source and generated Pages | CC-BY-4.0 |
| Original reports, fixtures, graph snapshots and receipts in `evaluation/`; original reference descriptions in `references/` | CC-BY-4.0 |
| Root prose and research metadata, including author/citation and license-scope declarations | CC-BY-4.0 |
| Original source, scripts, tests and dependency manifests in `tools/` and `tests/`; repository build configuration | MIT |
| Third-party works, dependencies, license texts and separately published manuscripts | Their own terms; see [NOTICE.md](NOTICE.md) |

Scientific outputs do not inherit their generator's software license. Code excerpts embedded in documentation retain the software license. The two licenses cover different scopes; they are not alternatives for a user to choose between on the same artifact. The directory-level declaration also covers preserved evaluated files whose embedded metadata has no license value; no semantic input or historical receipt is rewritten just to add a notice.
