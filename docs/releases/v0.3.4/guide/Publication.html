Current pages and frozen snapshots

Use the current portal for maintained explanations and the version index for registered frozen snapshots. Documentation 0.2.0 deliberately retains pre-publication #41/v0.3.2 wording under its explicit historical banner. Current 0.3.0 descriptions supersede that current-status wording without rewriting the snapshot. Legacy rc.1 and documentation 0.1.0 likewise retain exact registered bytes.

This refresh does not register a v0.3.4 snapshot. The release plan requires an exact committed documentation source, explicit component selection and successful final-source gates before freezing/publishing v0.3.4. Model, source-distribution and documentation versions are different identities.

Verify a publication

Pages deployment follows successful documentation CI for the same main-branch source; its root manifest identifies that source and deployed file hashes. Generation, tests, CI, deployment, actual HTTPS bodies and browser interactions are separate evidence. Passing a build is not a live readback.

Native Wiki requires its own write and a fresh Git readback against the generated projection. Markdown in the repository alone does not establish live synchronization. The work plan and artifact register distinguish current and historical results. No new HermiT/SHACL outcome, independent semantic rating, organizational admission or production acceptance follows from this documentation publication.
