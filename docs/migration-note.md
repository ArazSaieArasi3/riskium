# Public design import

The current import establishes conceptual design 0.3.1 and English documentation. It retains stable concept and relation identities, endpoint cardinalities, inheritance and interpretation constraints. Explanatory rationale was translated, identifying attribution was removed, and historical acquisition and execution metadata was kept outside the public export.

The complete model owns semantic definitions. Its typed projection and generated reference are derived views. Selected and complete conceptual diagrams are inspection aids; they do not certify native OntoUML conformance.

Relational implementations, populated case-study data and manuscript drafts are outside this import. Planned formal-test obligations are not reported as executed tests. See the migration integrity record and the roadmap for the exact scope.
