Abstract

Riskium distinguishes a continuing risk case from its records, scenario specifications, assessment artifacts and supporting evidence. This bounded OWL mapping expresses selected class, relation and restriction commitments from the conceptual model. It is narrower than the full conceptual catalog.

77 local named classes, one local external-anchor proxy and 127 object properties. Three optional concepts and seven bridges are outside this export. The local anchor does not establish an external import closure.

How to read this reference

Each entry gives its IRI, definition when supplied, and the axioms asserted in the source. Domain and range statements describe OWL typing commitments; they are not data-admission checks. OWL uses an open-world interpretation and does not assume that different names denote different individuals. Read the formalization explanation for mapping limits and the separate SHACL/application routes.
