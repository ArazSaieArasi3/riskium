Evaluation and limitations

The first stable owner-reviewed scope is published as v0.3.1. Current engineering supplements are recorded separately. A requirement, an expected result, an actual engine execution, an author judgment and an independent judgment are different evidence records.

The HermiT receipt, SHACL ledger, shared-graph receipt, database assurance, source CQ06 and source correction/identity receipt identify exact inputs and populations. Historical NOT_RUN/PARTIAL rows are not relabeled by later alternatives.

Owner review accepted the finite first-final scope with assistant support. It is not independent review. The current work plan retains broader mapping, formal/application rules, independently prepared cases, legitimate normative-source interpretation, independent reviewers and actual deployment/user acceptance. Synthetic data can expose engineering defects; it cannot provide independent source truth, domain adequacy or an overall correctness percentage.
