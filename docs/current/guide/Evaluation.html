Riskium/Evaluation

Evaluation and limitations

The ontology model is 0.3.1. Source distribution v0.3.2 includes the selected engineering supplements with their own versions; later Pages changes remain separate. A requirement, an expected result, an actual engine execution, an author judgment and an independent judgment are different evidence records.

Recorded evidence

Evidence population Recorded result Interpretation
HermiT baseline 693 matching cases; 281/295 scoped PASS, 14 NOT_RUN Bounded encoding/entailment evidence; not domain truth
Historical SHACL ledger 341 scoped PASS, one PARTIAL, 17 NOT_RUN /359 Module coverage; global C-08 remains PARTIAL
Later C-08 compatibility 37 actual SHACL runs plus four preflight controls Named supplementary declaration policy, not full conversion/computation
Selected comparison 50 actual SHACL runs plus five preflight controls Exact scale/version/dimension and interpretation joins
Shared-graph integration 0.1.0 31 expected outcomes: 21 SHACL, nine preflight, one raw preservation Selected task composition; four deleted-rule controls are within the 21 runs
SQLite assessment 0.2.0 48 fixed controls and 100 frozen generated inputs; two SQL-exported SHACL validations Selected mapping/history/query/migration evidence, not complete ontology mapping
Source CQ06–CQ08 13 selected source statements, five original/reissued pairs, 11 WITHHELD identity candidates Finite source tasks; no fabricated organizational case admission or whole-extraction accuracy
Independent semantic review Protocol prepared; zero actual reviewers, ratings and adjudications No independent acceptance result exists

Interpret the results

The HermiT receipt, SHACL ledger, shared-graph receipt, database assurance, source CQ06 and source correction/identity receipt identify exact inputs and populations. Historical NOT_RUN/PARTIAL rows are not relabeled by later alternatives.

What remains open

Owner review accepted the finite first-final scope with assistant support. It is not independent review. The current work plan retains broader mapping, formal/application rules, independently prepared cases, legitimate normative-source interpretation, independent reviewers and actual deployment/user acceptance. Synthetic data can expose engineering defects; it cannot provide independent source truth, domain adequacy or an overall correctness percentage.
