Requirement and competency-question traceability

This is the original source-bound requirement/CQ checkpoint, not a replacement for later dated SQL/source/owner/publication evidence. Historical acceptance states remain unchanged; current completion and remaining work are identified in the Work and release plan.

Conceptual design 0.3.1; semantic source cfb85905ab37549c7090f00a41ca62cdd3364ab5. This post-prerelease author trace review completes #6 as evidence reconciliation, not full requirement or independent scientific acceptance.

All 12 requirements, eight scope obligations and eight CQs have source hashes, exact model identifiers, acceptance/rejection criteria, current evidence and named remaining routes. The 20 Combined baseline identities are reconciled; eight scope rows remain outside the 674-row denominator.

Eight query contracts executed 40 local SPARQL queries: 32 fixed answer cases and eight successfully executed, detected query mutants. Five original synthetic-task contracts now have bounded execution. CQ06–CQ08 have synthetic controls only; their declared independent evidence-preservation population remains NOT_RUN in #13. Query execution does not prove native-only adequacy or real-data acceptance.

Evidence and reproduction

The full ledger retains source hashes, original criteria, exact model element hashes, baseline IDs and historical formal receipt/case IDs. Public identity continuity reconciles 345 retained public identities (317 model/domain elements plus 28 requirement/scope/CQ records) from the first public import. Restricted acquisition records and pre-public denominators are not copied or claimed reconciled.

The CQ receipt, contract/oracle files, named fixtures, eight SELECT queries, query mutants and supplementary data policy are separately inspectable. Values/locators/correction metadata outside the core are explicitly identified. All populations are synthetic; independent literature data preparation and expert acceptance remain #13/#7.

Use --write only after reviewing an intentional input/oracle change. The query receipt records execution time, Python/RDFLib versions, per-case expected/observed rows, graph snapshots, query hashes and the declared inference policy. A query error never counts as a detected mutant. Negative and conflicting fixtures are retrieval tests, not claims that those graphs satisfy managed admission. Missing asserted values are not logical negation.

Historical HermiT coverage remains 281/295, 14 NOT_RUN. SHACL remains 341 scoped PASS, 1 PARTIAL, 17 NOT_RUN / 359. Report sizes, test counts and the 28-row trace denominator are separate from semantic correctness.
