    Riskium/Limitations

    Scope and limitations

    The latest source distribution is v0.3.2, with a verified publication receipt. The ontology model remains 0.3.1. Current conceptual and OWL downloads preserve its exact source published with v0.3.1; current explanations and interface changes have separate source hashes. The later Pages/WebVOWL interface is not retroactively included in the source assets.

    This documentation keeps the selected OntoSPK/WIDOCO reading structure. Shared registered sources generate both Wiki and equivalent Pages explanations. The current portal can change; the version index identifies exact registered frozen documentation snapshots. The historical rc.1 route preserves the complete website observed at 3f332ea56cb27263d2435fa0ae20afb7a5d5f432, whose semantic source remains cfb85905ab37549c7090f00a41ca62cdd3364ab5. This is a dated legacy snapshot, not an invented claim that its earlier explanatory pages had always been immutable. Documentation versions and model/source release identities are distinct; the deployment manifest records the exact deployed source and file inventory.

    The complete conceptual catalog contains 80 concepts, including three optional boundaries, and 134 associations or bridges. The bounded OWL export has 77 local named classes, one local external-anchor proxy and 127 object properties. It excludes the optional boundaries and seven bridges. The anchor does not bundle an external ontology or establish its import closure. The ontology IRIs are identifiers; no dereferenceable vocabulary service is claimed.

    The explorer follows asserted named parents, children, domains and ranges in the frozen OWL graph. Its hypertext neighborhoods and local text filter work without an external visualization service. They do not materialize inferences or validate uploaded data. All term links remain available without JavaScript. The WIDOCO page is static and retains its generator credits. No page uploads a model, loads third-party runtime assets, sends analytics or stores browsing data.

    HermiT records 693 executed passing cases, covering 281 of 295 baseline obligations; 14 routes remain NOT_RUN. The SHACL module ledger records 341 scoped PASS, one PARTIAL and 17 NOT_RUN of 359. These are distinct populations with explicit scopes. Later C-08 compatibility, selected comparison, shared-graph integration, SQL and source-query supplements provide separately bounded evidence; they do not change those historical rows or establish full conditional/multi-relation task acceptance. Independent semantic judgment remains unrecorded. A generated reference, graph-isomorphic serialization or successful deployment does not establish semantic correctness.

    The scientific artifacts use CC BY 4.0 and original software uses MIT, under the rights declaration. Bundled WIDOCO template resources retain their upstream terms and notices. Copyright remains with the three authors for their respective original contributions; affiliations are recorded in Authors. No DOI, published-article status, production readiness or stable scientific acceptance is asserted.

    The current work plan identifies remaining formal/application rules, source-backed cases, normative-source interpretation, independent review and deployment acceptance. WIDOCO, the text explorer and WebVOWL are implemented views. WebVOWL shows only a fixed named-endpoint/subclass projection and a selectable visible neighborhood; its coverage inventory identifies omitted RDF statements. Improving the interface does not complete the remaining scientific work.
