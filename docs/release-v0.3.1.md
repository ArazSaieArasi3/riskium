# Riskium v0.3.1

First stable **bounded research-artifact release** of the Riskium risk-knowledge model. It consolidates rc.1–rc.7 and the owner's explicit scoped review. Stable means a maintained, versioned and reproducible artifact within the accepted limits; independent scientific certification and production readiness are not claimed.

## Verification and scope

The exact final candidate must pass the full engineering check list and fresh scoped compatibility, comparison, SQL history and source-query replays, followed by new-tag/asset checks and a separate downloaded final readback. The uploaded freeze receipt states the exact commands, runtimes and outcomes; source inventory and SHA256SUMS bind every packaged file/asset. Historical HermiT and early SHACL receipts remain source-bound evidence, not new full engine executions at this freeze.

Historical ledger: HermiT 693 matching finite cases, 281/295 obligations PASS and 14 NOT_RUN; consolidated SHACL 341/359 scoped PASS, one PARTIAL and 17 NOT_RUN. Later supplements retain separate populations, including 41 compatibility scenarios (37 actual SHACL runs), 55 comparison scenarios (50 actual SHACL runs), 67 SQLite scenarios, 35 CQ06 and 59 CQ07/CQ08 query/control outcomes. These populations overlap and are not a semantic-correctness percentage.

Owner review is disclosed as author/owner review with assistant support: nine scoped acceptances, an implemented prose revision and an accepted publication condition. Final technical evidence satisfies that condition without inventing another owner response. Independent review remains future #23. No critical retained-scope defect may be waived to publish.

Full score computation, temporal/workflow execution, generic risk-record readiness, full private-schema migration, PostgreSQL, universal scale conversion, independent population accuracy and full standards compliance remain outside current executable/scientific claims. Original MUST priorities are not lowered or marked fully fulfilled. Broader #4/#5/#12/#13/#16/#23 work remains later under these boundaries.

## Reproduction and maintenance

Install pinned dependencies from tools/requirements-shacl.txt and tools/publication/requirements.txt. On the exact tagged clean checkout run `python tools/prepare_stable_release.py --output /absolute/empty/path/out`; output must be outside the checkout. The stable profile is separate from the prerelease-only guard. Already-published tags/assets are never overwritten. Corrections use a newly named reviewed version.

The documentation portal retains the selected OntoSPK-style navigation, WIDOCO reference and explorer. Its manifest distinguishes frozen semantic input from current explanatory guides; the immutable source release and final publication receipt are authoritative for package identity. Scientific artifacts use CC BY 4.0 and original software uses MIT; see RIGHTS.md and third-party notices. No DOI is invented.
