# Riskium v0.3.7: source-qualified risk-nature assertions

**Prepared release notes. This distribution is not yet frozen or published.**
The published baseline remains v0.3.6 until the final release record says otherwise.

## Release goal

Deliver a reproducible source package for recording and retrieving the nature of
an organizational risk case, including the exact term and scheme versions,
context and objective links, documentary sources, corrections and recording
history. A later unrelated version must not silently change a historical answer.

## Changes since v0.3.6

- Add the bounded risk-nature SQL profile **0.9.0, SQLite schema 10**, extending
  assessment selection 0.8.0/schema 9. Expose internal Python retrieval by exact
  version, family and case; preserve exact documentary dependencies and source IDs.
- Preserve original and corrected assertions separately, independent scheme
  families and append-only recording revisions. Report absent context and unknown
  readiness explicitly; documentary recording is not semantic truth or authority.
- Advance current consistency to **0.5.0**: 470 trace routes and ten nature-task
  requirements, with all 306 native dispositions accounted and 31 bounded native
  route witnesses. Historical 236 deferred mappings and 65 paper dispositions
  retain their original meanings.
- Select reviewed documentation **0.4.4**: a concrete report/correction example,
  three audience paths, a reproducible Python example, organized repository
  landing and source-equivalent native Wiki and Pages guidance.
- Add versioned source-package qualification on main. Current tests run on the
  current source; all 16 unchanged historical reader tests run at their reviewed
  source commits. Immutable legacy diagnostics remain separate from v0.3.7 gates.

variants. Actual source-qualified test counts, run identities and artifact hashes

## Interpretation and limits

This is a bounded application-engineering and evidence-packaging increment.
Model and OWL semantics remain **0.3.1**; this is not a new scientific engine run,
full native-to-SQL mapping, production acceptance or independent semantic rating.
All eleven organizational admissions remain WITHHELD; independent ratings remain
zero. The new engineering routes are not promoted into manuscript 7.0.8 claims.
