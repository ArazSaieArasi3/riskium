# Riskium v0.3.1-rc.2 development prerelease

This development package consolidates the public work completed after v0.3.1-rc.1. The conceptual baseline remains **0.3.1**. It introduces no new class, relation, OWL axiom or claim of independent semantic acceptance. The original v0.3.1-rc.1 tag and archive remain unchanged.

## Included improvements

- Public requirement/CQ trace accounting: 28 rows, 32 fixed synthetic answer cases and eight detected query mutants. Five original synthetic-task contracts execute; CQ06–CQ08 still lack their independently prepared populations.
- Edition/portion-qualified source register: 11 selected sources, 13 interpretation rows and explicit access limits. Detailed normative appetite/tolerance definitions remain unassessed.
- Claim-based quality synthesis with distinct denominators, all 25 constraint routes, historical evidence hashes and explicit unknown independent validity.
- Manuscript 7.0.7 reconciliation: 65 claim/number/disposition rows and document QA. The public package contains the review ledger; the author-facing Word/PDF files and private SQL/pharmaceutical companions are not included as public assets.
- OntoSPK-style documentation portal, WIDOCO reference and bounded asserted-OWL explorer from the post-rc.1 documentation work. Website semantic inputs remain pinned to their declared released source, while narrative source hashes are separate; this source archive does not relabel the old portal as a new semantic model.
- Repeatable checked candidate packaging, exact tracked-source inventory and a reviewed release-request path. Automatic candidates and actual published prereleases remain distinct.
