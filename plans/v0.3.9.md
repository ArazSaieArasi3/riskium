# Coordinated Riskium package v0.3.9

## Selection and publication boundary

R1 selects scientific source **0.3.2** and documentation **0.4.9**. This is a
package version, separate from the scientific source and component versions.
The selected source combines the reviewed EvidenceUse repair, explicit
generalization-set policy and adopted analytical RiskCase definition. Selection
does not publish a release or change the maintained default channels.

The original 0.3.1 source, receipts and existing public database profiles remain
frozen. The 32 v0.3.8 components are retained as explicitly historical references,
with their original version and dependency bindings. They are not newly accepted
0.3.2 implementations. In particular, full SQLite/PostgreSQL migration is not
implied. The selected task-profile checks use a bounded historical SQLite
identity/history slice and synthetic RDF inputs; they do not establish production
or ecosystem-wide effectiveness.

## R1 acceptance

1. All selected input bodies match the manifest; the dependency graph is acyclic.
2. The metadata-only source promotion is reproducible; no prior receipt is rewritten.
3. The 20 predeclared RiskCase oracles are rerun against source 0.3.2, including
   schema/SDK, HermiT, OWL 2 DL, SHACL, a guard mutant and bounded SQL–SPARQL parity.
4. The complete source reader and both 89-page publication projections are rebuilt
   from the same source and checked for hashes, local routes and anchors.
5. Actual CI qualifies an exact commit; generated publication outputs retain that
   commit. No staged output is called deployed.

## R2 acceptance and endpoint

R2 creates and independently verifies the six public package assets, then
publishes the exact qualified source. Repository, Wiki and Pages maintained
entry points must be updated and read back against that source. Only after the
remaining issue-specific criteria pass may #92 or #93 close. Release preparation
does not require completion of unrelated future database/product work.

Expected public assets: `riskium-v0.3.9-source.tar.gz`, `source-manifest.json`,
`artifact-versions.json`, `freeze-receipt.json`, `release-notes.md`, `SHA256SUMS.txt`.
The release/tag and download round trip are intentionally not performed by R1.

Manuscript 7.2.21 remains unchanged; article binaries are not packaged here.
