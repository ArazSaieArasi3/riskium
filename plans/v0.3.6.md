## Reader outcome

An integrator can ask which assessment version was explicitly selected for a particular decision context at a stated point in the application ledger. The answer returns that version's original complete result bundle. A reviewer can retrieve the original assessment, every correction branch and the earlier answers after a selection, withdrawal or clear.

For example, context X selects A-v1 and later A-v2, while context Y selects A-v3. Withdrawing A-v2 in X returns WITHDRAWN in X, with no selected version or fallback. Earlier X queries still return their original answer, and Y still returns A-v3. A new correction does not select itself. Unknown values remain unknown.

The decision context is application metadata. It does not replace an assessment's pinned native context, method, scale, basis or time. Selection documents a choice; it does not establish truth, authority, comparability or completion of an actual assessment activity.
