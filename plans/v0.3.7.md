## Intended outcome

An integrator can retrieve the exact nature assertion version a source recorded for one RiskCase, including its local scheme-qualified nature term, pinned context/objective versions and original provenance. A reviewer can recover the original and every explicitly declared correction branch while another source's competing report remains distinct. Missing mandatory information remains raw; missing optional context or objective references stays visible as a fixed not-ready outcome.

The finite example has an original unfavorable report A-v1, a favorable correction A-v2, an alternative mixed correction A-v3 and a competing source B-v1. Exact retrieval of A-v1 keeps context-v1/objective-v1 after A-v2 uses context-v2/objective-v2. A plain later A-v4 with no correction declaration stays outside the original correction family.

## Why this scope is supportable

Model 0.3.1 provides C005 documentary identity through G-07, native R-41/42/43/44 and context-to-objective RK2-011. NatureTerm inherits ClassificationTerm/VocabularyConcept, so its scheme-qualified identity also requires the existing R-05 and inheritance routes. These supporting roles are included only as needed for this task. No new native model element is needed.

Exact version pins, correction provenance and readiness are supplementary engineering bindings. The contract respects optional context and requires real mandatory targets and pre-issuance recording links. It therefore avoids introducing a direct nature-to-objective relation or rewriting an issued entry/context to complete a missing link.

Broad ClassificationAssertion/RecordStateAssertion implementation, general taxonomy/objective governance, automatic selection or truth, formulas, workflow/authority engines, PostgreSQL/private migration and deployment acceptance remain excluded. Later research consolidation follows #37/#13/#4/#5, while actual independent review #23 can proceed when eligible reviewers are available. No later version number is allocated until its supported scope is known.
